# Using Plasma Next Dock

## Set up your first dock

Launch **Plasma Next Dock** from the applications menu. Right-click the capsule and choose **Configure Plasma Next Dock…**. Open **Applications and sorting → Add an application** to pick your launchers. You can also pin a running application from its context menu or drag an installed launcher onto the dock.

Choose an edge and screen in **Position and visibility**. **Always visible** reserves space for maximized windows, **Auto hide** reveals the dock at its edge, and **Dodge windows** hides the dock when a window overlaps it. Use **Apply** after changing appearance or position. Pinning an application and rearranging modules take effect immediately.

Use the dock selector and **Add dock** to create another profile. Each profile has its own launchers, filters, modules and appearance. Select **Primary screen** to follow the primary display, or select a named output to keep that dock on its assigned screen. The login setting applies to the entire collection.

## Arrange and use modules

Open **Modules** and drag a module between the three columns. The top entry of each active column appears at the outer end of that side of the dock. Modules with settings have their own configuration button.

- **Applications menu.** Browse categories and subfolders, search, or keep frequently used applications in Favorites. Drag favorites to reorder them or drag an application onto the dock to pin it.
- **Unpinned applications.** Show running applications that have no launcher on this dock. Configure sorting from the module’s context menu. Drag one of its applications into the pinned area to keep it.
- **Folders.** Add a directory from Dolphin. Drop files on an existing folder shortcut to copy them into it. To insert a new folder shortcut at a specific position, hold the dragged folder over the dock for two seconds, then drop it in the gap. In manual sort mode, you can reorder shortcuts on the dock.
- **Trash.** Drop external files here to move them to Trash. Dragging a pinned launcher or a folder shortcut from the dock onto Trash removes the shortcut.
- **USB storage.** The module shows removable volumes and their mount state. Drag a mounted volume onto Trash to unmount it. For an unmounted volume, the dock offers safe removal when the device is eligible.

## Switch windows and drop documents

Hover over a running application to see window previews. When dragging a document over a group, pause to open the previews, then hover over the window you want to bring forward. Move into that window to continue the drop. Dropping directly on the application icon opens the document with that application.

When the dock is full, scroll with the wheel or touchpad. During a drag, hold the item near either end to scroll without releasing it. [File and launcher drops](external-drops.md) · [Window previews](window-previews.md)

## Use the keyboard

| Action | Keys |
| --- | --- |
| Focus a dock and cycle through available docks | Meta+Alt+Space |
| Move between icons | Left / Right on a horizontal dock, Up / Down on a vertical dock |
| Jump to either end | Home / End |
| Open a launcher, activate a task, or show a group’s windows | Enter or Space |
| Open the selected icon’s context menu | Menu or Shift+F10 |
| Return from a preview or leave keyboard navigation | Escape |

The Plasma launcher shortcut (normally **Meta**) opens the dock’s Applications menu on an eligible output when the module is enabled there. A native Plasma launcher on that output takes priority. Inside the menu, use the arrows to move between the categories, application list, and session controls. Press Enter to activate the selection.

## Explore the appearance settings

Use **Appearance** to choose the background, tint, blur, border and corner radii. In **Free** mode you can set the capsule thickness independently of the icons. **Extend the Dock** stretches the background along the selected edge. **Icons and animations** controls magnification, hover lift, spacing and icon colors. Use **Indicators** to distinguish running and active windows.
